# Gaming User Analytics Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard analysing player engagement, retention, device usage, geographical distribution, application-version activity and key events. The project combines data visualisation, player segmentation, a conceptual user journey funnel and product recommendations to support data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- User and Event Analytics
- Product Analytics
- GitHub

## Dashboard Highlights
- **KPI Metrics:** Active players, retained players and geographical reach.
- **Engagement Analysis:** Trends in engagement time and sessions per active user.
- **Device Analysis:** Player activity across mobile device models.
- **User Trends:** Changes in player activity over time.
- **Key Events:** Analysis of `first_open` and `session_start` events.
- **Retention Analysis:** Player activity across successive periods.
- **Geographical Analysis:** Distribution of players by country.
- **Version Analysis:** Comparison of activity across application releases.

## Player Journey Funnel
The conceptual funnel covers six stages: discovery, download and installation, onboarding, tutorial completion, level progression and in-game purchases.

**Note:** Funnel figures are illustrative dummy data and should not be treated as verified conversion rates.
